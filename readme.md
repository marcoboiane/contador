🔢 Contador Simples

Um projeto simples de contador numérico desenvolvido para praticar conceitos básicos de desenvolvimento web utilizando HTML, CSS e JavaScript.

🚀 Funcionalidades
➕ Aumentar o valor do contador
➖ Diminuir o valor do contador
🔄 Resetar o contador para zero
🛠️ Tecnologias utilizadas
HTML5 — Estrutura da página
CSS3 — Estilização e layout
JavaScript — Lógica e interação do contador
📂 Estrutura do projeto
contador/
│
├── index.html
├── estilo.css
├── script.js
└── README.md
💻 Como executar
Clone este repositório:
git clone https://github.com/marcoboiane/contador
Abra a pasta do projeto.
Execute o arquivo index.html no navegador
🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais de HTML, CSS e JavaScript, incluindo manipulação do DOM e eventos de clique.
